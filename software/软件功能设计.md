# TC一键式导入软件

## 1.1 功能设计：

- 软件要求能够实现将物料总表Excel导入，生成TC表、EPlan的Excel表格；
  - 总表模板在/data/inputExample-total.xlsx，输出的TC表模板：/data/outputExample-TC.xlsx、Eplan表模板：outputExample-Eplan.xlsx

- 导入前要对物料总表做格式、合法性检查；合法性校验结果输出到文本文件中 log
- 总表导入可以选单个表、多个表；
- 导入的物料总表、导出的TC表、Eplan表有固定的格式，具体在/data/问价夹下；

## 1.3 校验细则

### 1、物料总表

代号一列不能为空；

部件编号（厂家代号）不能为空；

备注不能为空；

重量要求大于等于0，不填默认为0
