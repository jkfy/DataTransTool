# TC一键式导入软件

## 1.1 功能设计：

- 软件要求能够实现将物料总表Excel导入，生成TC表、EPlan的xml文件；
- 导入前要对物料总表做格式、合法性检查；合法性校验结果输出到文本文件 log中
- 总表导入可以选单个表、多个表；
- 导入的物料总表、导出的TC表、Eplan xml有固定的格式，具体在/software/templates/文件夹下；



## 1.2 导入导出规则

### 1、TC表

物料总表 ---> TC表、Eplan xml文件对应规则：



| 物料总表 | TC表           | Eplan xml文件                       |
| -------- | -------------- | ----------------------------------- |
| 序号     |                |                                     |
| 部件编号 | 部件编码       | P_ARTICLE_PARTNR                    |
| ERP编码  | ERP编码        | P_ARTICLE_ERPNR                     |
| 类型编号 | 类型编码       | P_ARTICLE_TYPENR                    |
| 名称1    | 名称1          | P_ARTICLE_DESCR1                    |
| 制造商   | 制造商         | P_ARTICLE_MANUFACTURER              |
| 供应商   | 制造商         | P_ARTICLE_SUPPLIER                  |
| 描述     |                | P_ARTICLE_NOTE                      |
| 数量单位 |                | P_ARTICLE_QUANTITYUNIT              |
| 重量     | 重量           | P_ARTICLE_WEIGHT                    |
| 宽度     |                | P_ARTICLE_WIDTH                     |
| 高度     |                | P_ARTICLE_HEIGHT                    |
| 深度     |                | P_ARTICLE_DEPTH                     |
|          | 是否合法：不填 | P_ARTICLE_MOUNTINGSPACE=宽度 * 高度 |
|          | 采购类型：不填 | P_ARTICLE_PARTTYPE:1                |
|          | 材料：不填     | P_ARTICLE_PRODUCTGROUP:0            |
|          |                | P_ARTICLE_PRODUCTSUBGROUP:0         |
|          |                |                                     |

注：

1. 总表模板位置：./templates/input_reference.xlsx
2. TC表模板位置：./templates/output_Tc.xlsx
3. eplan xml文件模板位置：./templates/output_Eplan.xml
4. 总表的第一行为表头。总表第二行为提示内容，不算正式数据，不需要导出。
5. TC表和eplan的xml表根据物料总表的对应关系进行填写。具体每一列对应关系见上表；
6. TC表中其他对应关系未提到的不填：是否合法、材料；





## 1.3 校验细则

### 1、物料总表

部件编码、类型编码、名称1、制造商、供应商这几列不能为空

重量、长、宽、高、深要求大于等于0，不填默认为0，其他情况报错
